# Layout Fix Plan — Restore Baseline + Independent Scrolling

## Root Cause

During the earlier revert, the grid div's Tailwind breakpoint utilities (`md:grid-cols-[minmax(0,40fr)_minmax(0,60fr)]` and `xl:grid-cols-[minmax(0,35fr)_minmax(0,65fr)]`) were accidentally dropped. The grid is currently `grid-cols-1` (single-column) on all viewports, which makes both panels stack vertically and look compressed.

## Fix (1 edit in 1 file)

**File:** `frontend/src/pages/Alerts.jsx` — grid div className (line ~437)

**Change:** Re-add the two fr-based breakpoint utilities:

```diff
- className={`alerts-workspace-grid mt-6 grid grid-cols-1 gap-6 ${
+ className={`alerts-workspace-grid mt-6 grid grid-cols-1 gap-6 md:grid-cols-[minmax(0,40fr)_minmax(0,60fr)] xl:grid-cols-[minmax(0,35fr)_minmax(0,65fr)] ${
      queueCollapsed ? "alerts-workspace-grid--collapsed" : ""
  }`}
```

**Why this is safe:** The CSS `.alerts-workspace-grid--collapsed` rule (which sets the 88px rail template at the same breakpoints) is unlayered CSS and wins over Tailwind's `@layer utilities` generated output via CSS cascade layer precedence. No CSS changes needed.
